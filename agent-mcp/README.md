# React Native Debugger Agent MCP sidecar

This is a dependency-free, read-only [Model Context Protocol](https://modelcontextprotocol.io/) stdio server. It is started by an Agent host, not by Electron. It connects to the **local Agent Bridge** created by a running React Native Debugger instance.

The Electron/worker bridge is deliberately outside this package. Until the bridge is implemented and enabled, this sidecar exits with a missing-discovery-file error.

## Start

```sh
node agent-mcp/src/index.js --discovery /absolute/path/to/agent-bridge.json
```

Or set `RNDEBUGGER_AGENT_DISCOVERY` to the same absolute path. With no option, the default is `~/.react-native-debugger/agent-bridge.json`.

The discovery file is generated by RNDebugger with mode `0600` and has this contract:

```json
{
  "version": 1,
  "pid": 12345,
  "origin": "http://127.0.0.1:43191",
  "token": "a-random-per-launch-token"
}
```

For defense in depth, this sidecar refuses non-loopback URLs and sends the token as an HTTP bearer token. The bridge must never bind to a non-loopback interface.

## Bridge API contract

All endpoints require the header above. Query arguments are passed through when supplied. Every response is JSON and includes `sensitiveDataMode: "redacted" | "raw"`.

| MCP tool | HTTP endpoint |
| --- | --- |
| `list_debug_sessions` | `GET /v1/sessions` |
| `get_console_logs` | `GET /v1/sessions/:sessionId/logs` |
| `get_redux_state` | `GET /v1/sessions/:sessionId/redux/state` |
| `get_redux_actions` | `GET /v1/sessions/:sessionId/redux/actions` |
| `get_network_requests` | `GET /v1/sessions/:sessionId/network` |
| `get_network_request` | `GET /v1/sessions/:sessionId/network/:requestId` |
| `wait_for_debug_event` | `GET /v1/sessions/:sessionId/events?after=:seq&limit=1` |

`wait_for_debug_event` has a maximum `timeoutMs` of 30,000. The bridge returns `{ event, cursor }` or a timeout result. It must not retain requests after the session disconnects.
Disconnected-session waits return promptly with `sessionDisconnected: true`;
previously captured events remain available only in the bridge's bounded
in-memory session buffers.

## Token-efficient read options

The sidecar sends only supplied non-empty arguments, apart from the documented
tool defaults below. This keeps broad reads small while still allowing an Agent
to ask for the exact detail needed to investigate an issue.

| Tool | Default output | Optional narrowing/detail arguments |
| --- | --- | --- |
| `get_console_logs` | `compact=true`, `limit=20`, `maxValueBytes=2048`, `maxResultBytes=32768` | `search`, `level`, `cursor`, `since` |
| `list_debug_sessions` | Session summaries, `maxResultBytes=32768` | Override `maxResultBytes` |
| `get_redux_state` | Latest state, `maxValueBytes=16384`, `maxResultBytes=32768` | JSON Pointer `path` |
| `get_redux_actions` | `includeState=false`, `compact=true`, `limit=20`, `maxResultBytes=32768` | `actionType`, `maxValueBytes`, `cursor`, `since` |
| `get_network_requests` | Summary only: `includeHeaders=false`, `includeBodies=false`, `limit=20`, `maxResultBytes=32768` | `method`, `url`, `status`, `bodyPreviewBytes`, `cursor`, `since` |
| `get_network_request` | `includeHeaders=true`, `includeRequestBody=true`, `includeResponseBody=true`, `bodyPreviewBytes=8192`, `maxResultBytes=32768` | Override any default above |
| `wait_for_debug_event` | `compact=true`, no state/headers/bodies, `maxValueBytes=2048`, `bodyPreviewBytes=4096`, `maxResultBytes=16384` | `after`, `eventTypes`, `timeoutMs`, state `path` when opted in |

`maxValueBytes` limits a serialized console or Redux value. `bodyPreviewBytes`
limits returned request and response body previews. A value of `0` requests no
value/body content while keeping the corresponding metadata.
`maxResultBytes` limits the total projected bridge response. It applies to all
list reads, Redux state, and a detailed network record; `0` retains response metadata but
no projected event/value content. The bridge reports truncation and its retained
cursor when a guard limit is reached.

MCP returns the full bridge payload only in `structuredContent`. Its text
content is a short mode/warning summary, so large logs, Redux values, and
network bodies are not duplicated in the final JSON-RPC response. Raw-mode
warnings are fixed-size and do not increase payload budgets materially.

## Sensitive-data switch

The default `sensitiveDataMode` is `redacted`. Only the RNDebugger UI can switch the current session to raw mode; this sidecar intentionally exposes no switch or mode argument. The sidecar never persists fetched data. Every raw tool result has a prominent `sensitiveDataWarning` field so a calling Agent can avoid copying it into tickets, logs, or external services.
